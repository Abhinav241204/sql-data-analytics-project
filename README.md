# SQL Data Analytics Project

A beginner-friendly SQL project focused on **data exploration, analysis, and reporting** using SQL.

## About the Project

This project demonstrates how SQL can be used to explore databases, analyze data, identify trends, and create meaningful reports.

The project covers both **Exploratory Data Analysis (EDA)** and **Advanced SQL Data Analytics**.

## Topics Covered

### Exploratory Data Analysis

* Database Exploration
* Dimensions Exploration
* Date Exploration
* Measures Exploration
* Magnitude Analysis
* Ranking Analysis

### Advanced Data Analytics

* Change Over Time Analysis
* Cumulative Analysis
* Performance Analysis
* Part-to-Whole Analysis
* Data Segmentation
* Customer Report
* Product Report
